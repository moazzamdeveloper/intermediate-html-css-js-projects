# 🚀 10 Intermediate HTML, CSS & JavaScript Projects

A curated collection of **intermediate-level** frontend projects to strengthen your skills in HTML, CSS, and vanilla JavaScript. Perfect for portfolio building and interview preparation.

Each project is self-contained, well-structured, and includes clean, modern code with comments.

---

## 📁 Projects List

| # | Project | Description | Key Skills |
|---|---------|-------------|------------|
| 01 | [Todo List App](./01-todo-app) | Full-featured todo with filters, edit, localStorage | DOM, localStorage, events |
| 02 | [Weather App](./02-weather-app) | Search weather by city (OpenWeatherMap API) | Fetch API, async/await |
| 03 | [Quiz Application](./03-quiz-app) | Interactive quiz with score & timer | Arrays, conditionals, timing |

## 🛠️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/moazzamdeveloper/intermediate-html-css-js-projects.git
   ```
2. Open any project folder and open `index.html` in your browser.
3. For the Weather App, get a free API key from [OpenWeatherMap](https://openweathermap.org/api) and replace it in the JS file.

## 🎯 Learning Goals

- Modern CSS (Flexbox, Grid, Custom Properties, Transitions)
- Vanilla JavaScript (ES6+)
- DOM manipulation & event handling
- localStorage for persistence
- Fetch API & async programming
- Canvas & Audio APIs
- Clean code structure and best practices

Start from **01 → 10**. Each project builds on previous concepts.
